## What's new

A smoother first install. No changes inside the app since 0.5.0.

- **Download in one click:** the README has a **Download for Mac** button that always gets the latest Brim.dmg.
- **First-open guide in the DMG:** the DMG window shows where to drag Brim and the three steps for opening it the first time.
- **Easier checksum check:** `Brim.dmg.sha256` now lists just the file name, so `shasum -a 256 -c Brim.dmg.sha256` works in your Downloads folder.
- **Built by GitHub:** this release was built, checked and published by GitHub Actions from the tagged commit, with build provenance you can verify.

## Install

1. Download **Brim.dmg** below (or use the button in the README).
2. Open it and drag **Brim** to **Applications**.
3. First open: macOS says it can't verify Brim, because it isn't notarized yet. Click **Done**, then open **System Settings › Privacy & Security** and click **Open Anyway**. You only do this once.

Updating from 0.4.0 or 0.5.0: use **Check for Updates** in the app; your Keychain and privacy approvals carry over.

From Terminal (builds on your Mac, no Gatekeeper step):

```bash
curl -fsSL https://raw.githubusercontent.com/abhargava14/brim/v0.5.1/install.sh -o install-brim.sh
chmod +x install-brim.sh
./install-brim.sh
```

Verify where the DMG came from (needs the GitHub CLI):

```bash
gh attestation verify Brim.dmg --repo abhargava14/brim
```
