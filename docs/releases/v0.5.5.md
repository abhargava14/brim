## What's new

Reliability fixes from a full review of the app. Nothing to set up.

- **Your data is safer:** if a notes, links, clocks, sites or connections file ever can't be read, Brim keeps a copy (`<name>.unreadable`) and never saves an empty list over it.
- **Claude sign-in stays working:** when Claude Code renews its login first, Brim picks up the new sign-in instead of showing "Sign in again". If you do need **Sign in again**, it now signs that same account back in instead of being refused as a duplicate.
- **Weather for other cities:** sunrise, sunset, the hourly chart and weekdays now show in the city's own time zone.
- **Steadier Claude limits:** with several Claude Code sessions open, the plan limits no longer flicker or disappear.
- **Safer updates:** the new version is copied in before the old one is removed, so a failed update leaves Brim in place. Updates also require a checksum.
- **Sounds:** recorded loops longer than 10 minutes are refused, since they're loaded into memory.
- **Analytics:** a key that couldn't be saved in your Keychain now shows an error instead of failing quietly.

## Install

1. Download **Brim.dmg** below (or use the button in the README).
2. Open it and drag **Brim** to **Applications**.
3. First open: macOS says it can't verify Brim, because it isn't notarized yet. Click **Done**, then open **System Settings › Privacy & Security** and click **Open Anyway**. You only do this once.

Updating from an earlier 0.5 or 0.4: use **Check for Updates** in the app; your Keychain and privacy approvals carry over.

From Terminal (builds on your Mac, no Gatekeeper step):

```bash
curl -fsSL https://raw.githubusercontent.com/abhargava14/brim/v0.5.5/install.sh -o install-brim.sh
chmod +x install-brim.sh
./install-brim.sh
```

Verify where the DMG came from (needs the GitHub CLI):

```bash
gh attestation verify Brim.dmg --repo abhargava14/brim
```
